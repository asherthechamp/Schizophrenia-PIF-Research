# Dataset

## OpenNeuro

Dataset: ds000030

Name: UCLA Consortium for Neuropsychiatric Phenomics LA5c Study

Snapshot: v1.0.0

DOI: 10.18112/openneuro.ds000030.v1.0.0

BIDS Version: 1.0.2

License: CC0

## Relevant Modality

Resting-state BOLD fMRI with physiological monitoring.

## Participant Inventory

From participants.tsv:

- CONTROL: 130 total; 127 with resting-state data
- SCHZ: 50 total; 50 with resting-state data
- BIPOLAR: 49 total; 49 with resting-state data
- ADHD: 43 total; 42 with resting-state data

## Primary Analysis

The initial analysis will compare:

SCHZ vs CONTROL

The bipolar and ADHD groups will not be included in the primary
schizophrenia analysis unless explicitly justified in a later analysis.

## Data Management

Raw OpenNeuro data are stored locally under:

data/raw/ds000030/

Raw and processed neuroimaging data are excluded from Git.

## Reproducibility

The dataset snapshot/version will be retained in the project
documentation so that analyses can be tied to a specific dataset release.
