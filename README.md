# Schizophrenia PIF Research

Computational neuroscience research project investigating the
Precision Instability Framework (PIF) in schizophrenia.

## Research Question

Do measures of temporal and functional instability distinguish
schizophrenia from healthy controls better than static measures
of mean functional connectivity?

## Initial Dataset

OpenNeuro ds000030

## Research Phases

### Phase 1 — Dataset and Replication
Replicate a known resting-state schizophrenia finding.

### Phase 2 — PIF Analysis
Compare static connectivity measures with dynamic instability measures.

### Phase 3 — EEG
Investigate temporal variability, oscillatory instability,
and potential precision-maintenance proxies.

## Project Structure

- `data/` — raw and processed data
- `notebooks/` — exploratory analyses
- `scripts/` — reproducible analysis code
- `papers/` — literature
- `figures/` — visualizations
- `results/` — analysis results
- `docs/` — research documentation
